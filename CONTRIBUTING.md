# Contributing to Application Tiles Webpart

Thank you for your interest in contributing to the Application Tiles SPFx webpart! We welcome contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone <your-fork-url>`
3. Install dependencies: `npm install`
4. Create a new branch: `git checkout -b feature/your-feature-name`

## Development Workflow

1. Make your changes in the appropriate files
2. Test your changes locally with `gulp serve`
3. Build the solution with `gulp bundle`
4. Ensure no TypeScript errors
5. Commit your changes with a descriptive message
6. Push to your fork
7. Create a pull request

## Code Style

- Follow TypeScript best practices
- Use meaningful variable and function names
- Add comments for complex logic
- Ensure accessibility standards are met
- Test on multiple browsers

## Testing

Before submitting a pull request:

1. Test in the local workbench
2. Test in SharePoint Online workbench
3. Verify responsive behavior on different screen sizes
4. Check accessibility with keyboard navigation
5. Verify theme compatibility

## Pull Request Guidelines

- Provide a clear description of the changes
- Reference any related issues
- Include screenshots for UI changes
- Ensure all tests pass
- Update documentation if needed

## Reporting Issues

When reporting issues, please include:

- SPFx version
- Node.js version
- Browser and version
- Steps to reproduce
- Expected vs. actual behavior
- Screenshots if applicable

## Questions?

Feel free to open an issue for questions or discussion.

Thank you for contributing! 🎉
